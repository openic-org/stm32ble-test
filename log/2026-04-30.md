### Phase 4 — Makefile build system (complete)
- Created `server/Makefile`, `client/Makefile`, and top-level `Makefile`.
- Key discovery: STM32Cube FW V1.4.1 is an incremental release — it only contains updated `Middlewares/` and `Projects/`. `Drivers/` (HAL, CMSIS, BSP) and `Utilities/` come from V1.4.0. Handled via two Makefile variables:
  - `CUBE_DRV_ROOT` → V1.4.0
  - `CUBE_MW_ROOT` → V1.4.1
- Source file list extracted from Eclipse `.project` linkedResources entries (not from `.cproject` include paths).
- Both targets build and link cleanly with `arm-none-eabi-gcc 14.3.1`.
  - Server: 125 KB flash, 64 KB RAM (100% — expected, BLE stack fills available RAM by design)
  - Client: 139 KB flash, 64 KB RAM
